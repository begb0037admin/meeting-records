## Deploy — done 16 Sep 2026

2. **Hostname confirmed**: `meeting.lelitte.co.uk` (Kevin, 16 Sep). `wrangler.toml` now carries `routes = [{ pattern = "meeting.lelitte.co.uk", custom_domain = true }]` and `[vars] ALLOWED_ORIGIN = "https://meeting.lelitte.co.uk"`. Note the TOML ordering matters here — `routes` must sit before any `[table]` header or it silently gets absorbed as a var inside the preceding table instead of being read as the top-level Custom Domains key; hit and fixed this live during this deploy (first attempt only bound `env.routes` as an env var, no route triggered).
3. **`wrangler deploy` run**: live. `meeting.lelitte.co.uk` confirmed serving the static UI (`HTTP 200`) and the API routes respond (`/api/meetings/list` returns `405 POST only` on a bare GET, confirming the route table is wired). The old default `*.workers.dev` URL is disabled (`workers_dev` unset now defaults to `false` once a custom domain route exists) and returns `404`.
