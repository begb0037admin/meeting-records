# H&S Roadmap 21 Sep 2026 build (scratchpad-derived, committed here for durability)

Not a change to `tools/speaking-briefs/build_hs_roadmap.py` (21 Aug pipeline-review freeze still applies). Implemented by Codex (lead implementer) from `PROMPT.md`; reviewed and verified by Lauren.

- `extract_hs_items.py` reads a COPY of the shared H&S workbook (`hs_workflow_copy.xlsx`, not committed) and writes `hs-items.json`.
- `content.json` is the authored content (generated by `author_content.py`). `build_hs_roadmap_2026-09-21.py` renders it with `brief_chrome.py`.
- To rerun: copy the live workbook to a scratch folder first (never open the shared original), put `brief_chrome.py`, the Inter woff2 files and `oxford-crest.jpg` alongside, repoint `SCRATCH` in the local copy of `brief_chrome.py`, then `python extract_hs_items.py` and `python build_hs_roadmap_2026-09-21.py` (set `HS_BRIEF_TEST=1` to avoid writing to OneDrive).
- `make_pending.py` builds `pending_hs_2026-09-21.json`, the payload written to `POST /api/intakes/pending/write` (secret from `MEETING_PREP_PENDING_SECRET`, never stored here).
